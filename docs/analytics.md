# 网站访问统计

主站使用独立的自建统计服务，不需要 Umami 账号。前端继续由 GitHub Pages 托管，采集接口和聚合面板部署在：

https://gpu-prism-analytics.alert-grass-7728.chatgpt.site/

仓库内的 `services/analytics` 保存可独立安装、构建和维护的服务端源码，包含接口、面板、数据库迁移、构建配置和服务端测试。相邻目录 `../gpu-prism-analytics` 是当前 Sites 托管工作副本。两处使用同一 `project_id`；维护服务时应同步源码，再从已绑定的托管工作副本按 Sites 流程发布。数据库和托管密钥不在 GitHub 源码中。

服务使用 Sites 托管接口和 D1 数据库。当前统计服务尚未开放匿名访问，主站 `public/analytics-config.json` 保持 `enabled: false`，因此暂未记录真实公开访问。接口完成部署并允许匿名访问后再启用。配置文件不包含密钥，使用 Vite 的 `BASE_URL` 加载，兼容 GitHub Pages 的 `/GPU_Prism/` 路径。

## 统计口径

- 浏览次数：初次进入页面和不同规范路由间的切换各记一次；同一路由重复渲染不重复计数。源码内的子模块聚合到所属项目，不采集代码路径。
- 访客数：浏览器生成匿名随机标识，同一浏览器重复访问可去重。不同浏览器或设备、清除浏览器存储会被视为不同访客，因此这是访客估计数，并非真实自然人数。禁止存储时使用当前页面内存标识。
- 模型互动：记录选择已收录 GPU/LLM、进入故事模式和故事自然播放完成。暂停、每帧动画以及自由输入内容不计数。
- 日期：面板按北京时间统计。从功能启用后开始积累，无法恢复启用前的访问记录。

前端仅在配置允许的正式域名运行，开发模式、localhost 和本地预览不会上报。开启浏览器 Do Not Track 或 Global Privacy Control 时也不会上报。

## 隐私与可靠性

客户端只发送随机请求 ID、匿名浏览器 ID、有限事件名、规范页面及静态模型 ID。不会发送完整 URL、查询参数、搜索文本、用户填写的模型配置或本地源码路径。服务端使用密钥摘要后存储访客标识，不保存原始 IP 或用户身份；网络服务处理请求时仍会接触连接信息。

采集凭证由 `/api/session` 匿名签发，短期有效，仅保存在当前页面内存中。服务端验证来源、凭证、事件白名单和请求大小，并通过请求 ID 去重。客户端最多排队 24 条待处理事件，每条最多尝试两次；不可用、被拦截或离线时自动放弃，不影响网站浏览与 3D 动画。网络拦截、隐私设置和机器人访问都会影响计数，应将结果作为趋势参考。

统计面板只展示汇总数据。主站页脚的「访问统计」入口仅在统计开关启用后显示。
