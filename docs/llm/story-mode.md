# LLM 故事讲解与组件剖面

LLM 页面支持自由探索和中文故事讲解。DeepSeek-V4.1-Flash 有八章，其他公开架构依据本地配置生成不同章节；Kimi-K2.8 Preview 未公开内部结构，不生成内部故事。

## 操作

在 LLM 页点击“故事讲解”。章节支持直接跳转、上一章、下一章、暂停与重播；拖动画面会暂停导览。退出后恢复进入故事前的层级、层号和显示选项。手机将讲解放在画布下方；系统减少动态效果时默认暂停，镜头与剖面直接到位。

故事会选择真实层号，聚焦相关组件，并突出连接它们的示意路径。DeepSeek 的 Full、Reindex 和 Reuse 分别定位不同层；Reuse 不播放重算索引的查询连接。局部 SWA 与全局稀疏分支使用不同的剖面读取图案。

故事的文字、读取扫描、缓存状态、路由光点和章节内运镜由同一播放时间驱动，暂停后一起停止。专家章节每隔一段演示时间切换一个教学 Token 的 Top-K 选择，并播放输入到专家、专家到汇合的路径。系统减少动态效果时保留固定镜头；显式点击继续仍会运行必要的机制动画，不受探索页粒子开关的旧状态影响。

在自由探索中点击组件会拉近镜头；接近注意力、缓存、状态和路由器时展开剖面。专家阵列总量继续取自模型配置，路由器内部最多显示 24 个抽样格，文字注明抽样和总量。格子不代表物理 bank、真实注意力权重或采集到的路由结果。

## 实现入口

- `src/llm/stories.js`：章节数据与可暂停的播放时钟。
- `src/llm/story-ui.js`、`story.css`：章节和控制界面。
- `src/llm/cutaways.js`：有边界的内部结构、外壳渐隐与材质复原。
- `src/llm/scene-semantics.js`：实例标识与路径焦点匹配。
- `src/llm/page.js`：场景、章节、镜头与选择的适配。

实例键由模型、LOD、层号、组件类别和顺序组成。章节保存选择条件而不持有网格引用，切换场景后重新解析目标。旧路径只解析与组件中心精确重合的锚点，不将附近曲线控制点解释为依赖；残差单独分类。这里的关系图是架构机制示意，不是从运行时追踪得到的执行图。

## 设计参考

章节、开放剖面与角色聚焦的设计受到 [InfraTech 架构可视化](https://github.com/CalvinXKY/InfraTech/tree/48e358a4b5119c24cf472adc64d0b4f86f894e99/models/3d_model_arch_tool) 启发。本次未复制其脚本、解说、模型资产或教学数值；章节与剖面基于本工程已有数据独立实现。

该参考实现有部分跨模型内部图形使用固定数量，本工程按已核实配置驱动数量，无法逐个展示的内部切片明确标为聚合或抽样。模型来源仍见各模型说明与页面中的官方资料链接。
