# INFAR · GPU 架构图鉴

一个可交互的 GPU 硬件架构网站。提供 NVIDIA H20 SXM5 96GB 的整体架构与 SM 内部结构，共六个探索视图。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

## 页面与交互

- `/#/gpus`：GPU 目录、架构筛选和搜索。
- `/#/gpu/h20`：H20 3D 探索器。
- 封装总览、芯片架构、SM 微架构，以及共享内存、寄存器文件、Warp 执行三个深入视图。
- 共享内存：32 bank 的逐 lane 地址映射，支持 stride、同址广播与 padding 实验，联动 3D 高亮。
- 寄存器：寄存器阵列、操作数收集与写回，附 Hopper/H100 参考资源预算实验。
- Warp：线程束池、取指译码、scoreboard、调度、发射、操作数、执行与写回；可逐步推进、模拟等待解除。
- 拖动旋转、右键平移、滚轮缩放、视角预设、自动旋转、组件标签、全屏。
- 点击 3D 模型、标签或组件列表，查看说明与推理关联。
- 分层展开、示意数据流、键盘快捷键、移动端布局。
- `1`—`6` 切换视图，`R` 重置视角，`E` 分层展开，`?` 打开指南。
- 深层视图支持直接访问：`/#/gpu/h20/shared`、`/#/gpu/h20/registers`、`/#/gpu/h20/warp`。

## 内容与模型边界

H20 产品信息参考 NVIDIA 官方 vGPU 文档与 Dell XE9680 规格；内部原理参考 NVIDIA Hopper 架构与 CUDA 调优文档。来源链接可在网页「数据来源」中打开。

3D 模型是功能关系的教学示意，不能作为实际芯片的 CAD、floorplan 或核心数量依据。不同版本与服务器配置可能有差异。没有将 H100 的 SM 数量、L2 容量与计算峰值套用于 H20。

共享内存示例限定一个 Warp 的每个活跃 lane 读取一个对齐的 32-bit word，并区分不同地址冲突与同址读取广播。寄存器资源模型采用公开 Hopper/H100 参考容量，忽略寄存器分配粒度、SM 分区和其他硬件约束，不代表 H20 的实测占用率。寄存器 bank、端口、操作数收集与执行阶段的物理数量、位置和时序未公开，图中均为功能抽象；流水线步进不表示真实周期。

## 结构

- `src/gpu-scene.js`：Three.js 模型、拾取、相机和动画。
- `src/deep-scenes.js`：共享内存、寄存器、Warp 的 3D 功能结构与实验高亮。
- `src/deep-lab.js`：交互实验面板。
- `src/hardware-models.js`：bank 映射、资源预算和指令推进的独立逻辑；以 `node --test` 运行测试。
- `src/main.js`：路由和交互。
- `src/data.js`：组件说明和资料来源，便于扩展 GPU。
- `src/style.css`：响应式样式。

静态网站，无后端，不收集用户数据。构建产物在 `dist/`。
